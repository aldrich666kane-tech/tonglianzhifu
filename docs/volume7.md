# 卷七 国际化篇 | 跨境布局与全球合作

## 【1】 全球支付体系对比 (Visa、UPI、UnionPay、CIPS)

全球支付市场由多个核心体系主导，它们在模式、覆盖范围和功能上各有侧重，共同构成了复杂的国际支付网络。

- **Visa/Mastercard**：作为全球最大的银行卡组织，其网络覆盖超过200个国家和地区。它们的核心模式是“四方模式”（发卡行、收单行、商户、持卡人），通过授权和清算服务，连接全球的金融机构和商户，以信用卡和借记卡业务为主，技术标准和品牌影响力深远。

- **UnionPay (中国银联)**：中国自主的银行卡组织，已成为全球发卡量最大的卡组织。银联通过“走出去”策略，网络已延伸至180多个国家和地区。它不仅服务于出境的中国消费者，也积极推动境外本地发卡和移动支付产品（如云闪付App）的国际化。

- **UPI (Unified Payments Interface, 印度统一支付接口)**：由印度国家支付公司（NPCI）推出的实时支付系统。UPI的特点是基于手机App，通过虚拟支付地址（VPA）实现即时、低成本的P2P和P2M转账，是移动支付国家战略的成功典范，正在向其他国家输出其技术模式。

- **CIPS (Cross-border Interbank Payment System, 人民币跨境支付系统)**：由中国人民银行组织建设的专用于人民币跨境支付的清算系统。CIPS旨在提高人民币跨境清算的效率和安全性，支持全球各时区的支付结算，是推动人民币国际化的核心金融基础设施。

## 【2】 中国跨境清算网络结构

中国的跨境清算网络是一个多层次、多通道的复合结构，旨在满足不同币种、不同场景的跨境支付需求。

- **主干通道**：
  - **CIPS**：处理人民币跨境业务的核心通道，连接境内外直接和间接参与者，实现人民币资金的“一站式”清算。
  - **SWIFT (环球银行金融电信协会)**：作为全球金融报文交换网络，长期以来是中国金融机构与国际同业进行外币（如美元、欧元）跨境支付报文传输的主要渠道。

- **辅助与补充通道**：
  - **代理行模式**：中资银行通过在境外开设分行或与当地银行建立代理关系，实现跨境汇款和结算。
  - **卡组织网络**：银联、Visa、Mastercard等卡组织的全球网络，主要处理个人消费和取现等零售支付业务。
  - **第三方支付机构通道**：如通联支付等持牌支付机构，通过与境外合作机构对接，为电商、留学、旅游等场景提供定制化的跨境支付解决方案。

## 【3】 通联跨境支付产品体系

依托境内外支付牌照和合作网络，通联支付构建了服务于B端和C端客户的综合性跨境支付产品体系。

- **收款类产品**：
  - **跨境电商收款**：为出口电商卖家提供从Amazon、eBay等主流平台收款的服务，支持多币种结算，提现周期短，费率透明。
  - **线下扫码收款**：支持境外商户受理境内消费者的微信支付、支付宝、云闪付等移动支付方式，方便中国游客消费。

- **付款类产品**：
  - **跨境汇款/付款**：为企业提供向全球供应商、员工支付货款、薪酬的服务，也为个人提供留学缴费、境外购物等付款解决方案。
  - **虚拟卡服务**：发行用于企业采购、广告投放等场景的虚拟信用卡，简化支付流程，便于费用管理。

- **解决方案**：
  - **全球资金分发**：为平台型企业（如共享经济、直播平台）提供向全球用户分发资金的一站式解决方案。
  - **外汇管理服务**：提供结售汇、汇率锁定等增值服务，帮助客户规避汇率风险。

## 【4】 人民币国际化与外汇合规

在推动跨境业务的同时，通联支付严格遵守中国及业务所在国的监管要求，将合规置于首位。

- **人民币国际化**：积极利用CIPS等基础设施，在跨境贸易、投资等领域推广人民币计价和结算，减少对第三方货币的依赖，降低企业的汇兑成本和风险。
- **外汇合规**：
  - **真实性审核**：严格执行交易背景真实性审核要求，对每一笔跨境交易的合同、订单、物流等证明材料进行核查。
  - **反洗钱（AML）与反恐怖融资（CFT）**：建立完善的客户身份识别（KYC）、大额与可疑交易监控和报告机制，对接国际制裁名单，防范金融犯罪。
  - **数据报送**：按照国家外汇管理局等监管机构的要求，准确、及时地报送跨境收支数据。

## 【5】 “一带一路”区域业务拓展

通联支付紧随国家“一带一路”倡议，将业务拓展的重点聚焦于沿线国家和地区，特别是东南亚、中亚等新兴市场。

- **市场策略**：
  - **本地化运营**：在重点国家设立分支机构或与当地有实力的金融机构、支付公司建立深度合作关系，深入理解当地市场和监管环境。
  - **场景渗透**：重点关注跨境电商、旅游、基础设施建设、劳务派遣等与“一带一路”倡议高度相关的支付场景。
  - **技术输出**：向合作伙伴输出成熟的支付技术、风控能力和运营经验，共同打造符合当地需求的数字支付生态。

## 【6】 数字人民币跨境试点

作为支付行业的探索者，通联支付密切关注并积极参与数字人民币（e-CNY）的跨境支付试点项目。

- **探索方向**：
  - **mCBDC桥项目**：关注并研究由国际清算银行（BIS）主导的多边央行数字货币桥项目，探索数字人民币在其中的应用潜力。
  - **零售场景试点**：与运营机构合作，探索数字人民币在跨境电商、个人消费等零售场景的应用，测试其在小额、高频支付中的效率和便利性。
  - **合规与技术挑战**：研究数字人民币跨境流动所涉及的“了解你的客户”（KYC）、“资金可控匿名”以及不同国家间监管协同等技术和政策挑战。

## 【7】 国际合作与伙伴图谱

通联支付的国际化战略建立在广泛而深入的合作基础之上，其伙伴图谱覆盖了全球支付价值链的各个环节。

- **金融机构**：与花旗银行、汇丰银行、星展银行等全球性银行以及众多区域性银行建立了代理行和清算合作关系。
- **卡组织**：作为银联、Visa、Mastercard等国际卡组织的成员，参与其全球收单和发卡业务。
- **本地支付网络**：与东南亚、欧洲、拉美等地区的本地支付工具（如电子钱包、本地转账系统）实现对接，构建“一点接入，覆盖全球”的支付能力。
- **技术与服务提供商**：与全球领先的身份验证、风险管理、合规科技（RegTech）公司合作，提升跨境业务的安全与效率。
